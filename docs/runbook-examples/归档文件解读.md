# 归档文件解读规程

## 步骤

1. **取归档目录与文件清单**：调用 `list_archive_files(tcat_id)`（tcat_id 即触发ID，如 `tn260717_120003_gbm`）。
   - 若只是想看"归档在哪、有哪些文件"，到这步即可作答。
2. **列文件清单**：按 `stage` 分组呈现（search / cut / analysis），给出文件名、类型、大小。
   - 表格只保留 5~6 列，长标识（run_id/t_cat_id）默认不列。
3. **解释每个文件**：结合文件名与类型说明其角色：
   - `*.tcat`：搜索阶段产出的候选触发记录。
   - `*_CUT_*.fits`：各载荷（GBM / GECAM / GRM）的切割产物。
   - `result_*_loc.fits`：联合**定位**结果；`result_*_joint.fits`：联合**分析**结果。
   - `location_*.json` / `external_location_*.json`：定位数值（RA/Dec/误差）。
   - `result_*.pdf`：分析报告。
4. **读内容/头**：需要细节时用 `read_archive_file(tcat_id, file_name)`；
   FITS 返回头关键字（TELESCOP/INSTRUME/OBJECT/DATE-OBS 等），文本文件返回原文。
5. **要文件本体**：用户明确要"发我/下载"时，用 `fetch_archive_file(tcat_id, file_name)` 生成下载链接。
6. **做分析并出报告**：需要统计/生成报告时用 `run_python_analysis`（把文件放进沙箱分析，产出文件回传）。

## 注意
- 归档目录以 `list_archive_files` 返回的 `archive_dir` 为准，**不要从文件名臆测子目录**。
- 文件类型只按扩展名/约定判断；不确定就如实说明。
